# MUMAI

تطبيق موبايل (React Native + Expo) لمتابعة الأم لمراحل نمو طفلها من الولادة، بمعايير مبنية على أطر WHO/CDC (Learn the Signs. Act Early)، مترجمة ومعاد صياغتها بالعربية.

## تشغيل المشروع

```bash
npm install
npm start
```

بعدها اختاري:
- `npm run ios` / `npm run android` لتشغيله على محاكي
- امسحي الـ QR code بتطبيق **Expo Go** على موبايلك لتجربته مباشرة
- `npm run web` لتجربته في المتصفح

## البنية

- `src/data/milestones.ts` — قاعدة بيانات المراحل العمرية (من الشهر الأول حتى 5 سنوات)، المهارات المتوقعة في كل مجال (حركي كبير/دقيق، لغة، اجتماعي وعاطفي، إدراكي)، وعلامات التحذير (Red Flags) مع الأسباب المحتملة والتخصص الطبي المقترح.
- `src/store/AppStore.tsx` — تخزين محلي (AsyncStorage) لبيانات الطفل وحالة إنجاز كل مهارة.
- `src/services/aiChatService.ts` — طبقة الحوار الذكي: تربط سؤال الأم بالبيانات الموثقة في `milestones.ts` (rule-based grounding)، وتدعم الاتصال بنموذج ذكاء اصطناعي حقيقي لو توفر مفتاح/باك-إند.
- `src/screens/` — شاشات الـ Onboarding، لوحة المتابعة الزمنية، تفاصيل كل مرحلة، والمحادثة.

## تفعيل الذكاء الاصطناعي الحقيقي (اختياري)

حاليًا الشات بيشتغل بنظام قواعد ذكي (rule-based) يطابق سؤال الأم مع بيانات المراحل ويرد برد منظم — يشتغل من غير أي إعداد إضافي.

لتفعيل نموذج AI حقيقي للحوار الأكثر مرونة:

1. **الأفضل (آمن للإنتاج):** جهزي باك-إند بسيط (proxy) يستقبل السؤال، يستدعي Anthropic API من السيرفر (مش من الموبايل عشان الـ API key ميتسربش)، ويرجع الرد. حطي رابطه في متغير البيئة:
   ```
   EXPO_PUBLIC_AI_PROXY_URL=https://your-backend.com/api/chat
   ```
2. **للتجربة المحلية فقط (غير آمن للإنتاج):** حطي مفتاح Anthropic مباشرة:
   ```
   EXPO_PUBLIC_ANTHROPIC_API_KEY=sk-ant-...
   ```
   ⚠️ لا تستخدمي الطريقة دي في نسخة منشورة للمستخدمين — المفتاح هيبقى مكشوف جوه التطبيق.
