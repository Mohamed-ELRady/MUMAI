# MUMAI

تطبيق عربي وإنجليزي لمتابعة نمو الطفل من الولادة لحد 5 سنين، مبني على React Native وExpo SDK 57. البيانات بتتحفظ محليًا على الجهاز.

## التشغيل والفحص

المتطلبات: Node.js 22.13 أو أحدث، وnpm.

```bash
npm ci
npm start
```

- `npm run web` لتجربة الويب.
- `npm run android` أو `npm run ios` لتشغيل نسخة متوافقة مع Expo SDK 57 على الجهاز أو المحاكي.
- `npm run typecheck` لفحص TypeScript.
- `npm test` لاختبار الشات، التواريخ، حفظ البيانات واعتماديات التنقل.
- `npm run build:web` لبناء نسخة الويب.
- `npx expo export --platform all` للتحقق من حزم JavaScript للويب وAndroid وiOS؛ ده مش بناء تطبيق native كامل.
- `npx expo-doctor` لفحص إعدادات Expo.

## الشات

الشات بيشتغل من غير مفتاح API باستخدام دليل النمو المحلي. بيفهم صيغ مصرية وعربية وإنجليزية، ويراعي العمر المذكور في السؤال، وسياق أسئلة المتابعة، وحالات المهارات المسجلة. بيوضح الأعمار المرجعية ومصدر الرد، ويحفظ أسئلة الأسرة محليًا عشان تظهر في تقرير الطبيب.

الاتصال بنموذج توليدي اختياري ومحتاج خادم وسيط. المشروع فيه Cloudflare Worker جاهز داخل `model-proxy/`. بيقبل نطاق الديمو فقط، يتحقق من حجم وشكل الطلب، ويضع حدًا أساسيًا لعدد الطلبات، ويحفظ مفتاح OpenAI كـsecret على الخادم. يستخدم Responses API مع `store: false` ويجبر الرد الطبي على الاستناد إلى سياق MUMAI وروابط CDC/NHS المرسلة مع السؤال. الرد المحلي يظل بديلًا تلقائيًا لو الخادم أو النموذج فشل.

للتجربة المحلية:

```bash
cp model-proxy/.dev.vars.example model-proxy/.dev.vars
# ضعي OPENAI_API_KEY الحقيقي في الملف المحلي؛ الملف مستبعد من Git
npm run proxy:dev
```

للنشر:

```bash
npm exec wrangler -- login
npm exec wrangler -- secret put OPENAI_API_KEY --config model-proxy/wrangler.jsonc
npm run proxy:deploy
```

بعد ظهور رابط الـWorker، انسخي `.env.example` إلى `.env.local` واضبطي:

```dotenv
EXPO_PUBLIC_AI_PROXY_URL=https://your-backend.example/api/chat
```

المتغير ده **رابط عام فقط**. مفاتيح Anthropic أو أي مقدم آخر تتحفظ على الخادم؛ التطبيق لا يستدعي مقدم النموذج بمفتاح مكشوف. بعد تغيير الرابط، أعيدي تشغيل Expo أو بناء الويب.

الخادم يستقبل `POST` من نوع JSON:

```json
{
  "query": "ابني مش بيتكلم",
  "context": {
    "babyName": "يوسف",
    "ageMonths": 18,
    "currentStageId": "m18",
    "lang": "ar",
    "completedMilestoneIds": []
  },
  "history": [{ "role": "user", "text": "عمره سنة ونص" }],
  "grounding": "مراجع النمو المناسبة للسؤال والعمر"
}
```

ويرجع:

```json
{ "reply": "الإجابة هنا" }
```

النصوص الواردة من العميل بيانات وليست تعليمات موثوقة للخادم. تاريخ المحادثة المرسل محدود بآخر 12 رسالة وبحد 2000 حرف للرسالة. لا تضعي مفتاح OpenAI في متغير يبدأ بـ`EXPO_PUBLIC_` أو في ملفات المشروع.

التطبيق ينتظر 12 ثانية بحد أقصى، ويتحقق من الرد، ثم يرجع للدليل المحلي مع رسالة واضحة عند فشل الاتصال أو رجوع محتوى غير صالح. إشارات الطوارئ وفقدان المهارات المعروفة للمطابق المحلي تُعرض مباشرة من غير انتظار الخادم.

إجابات الكلام والجلوس والمشي تبدأ بالمتوقّع في عمر الطفل، ثم مهارات المرحلة وأنشطة مناسبة لها. مثلًا سؤال «إزاي أساعده يتكلم؟» لطفل 7 شهور يشرح إن الكلمات ذات المعنى لسه مش متوقعة عادة، ويركّز على المناغاة وتبادل الأصوات. الأعمار اللاحقة تُذكر عند السؤال عن التوقيت، ولا تُستخدم للحكم على طفل أصغر. المنطق نفسه يدخل في المراجع المرسلة للخادم، ويحتفظ بأسئلة المتابعة وتصحيح العمر. غياب مهارة حالية أو الاستجابة للأصوات وفقدان المناغاة يستدعي توجيهًا للتقييم، حتى لو الكلمات لم تُتوقع بعد. الدليل المحلي يعتمد على قواعد ومحتوى محدد، وليس فهمًا مفتوحًا لكل صياغة.

## حفظ البيانات

تاريخ الميلاد يُحفظ كتاريخ تقويمي `YYYY-MM-DD` لتجنب تغيير اليوم بسبب المنطقة الزمنية. لكل مهارة ثلاث حالات: «بيعملها»، «بيحاول»، و«لسه ملاحظتهاش». العلامات القديمة تُرحّل تلقائيًا إلى «بيعملها». تُحفظ أيضًا إنجازات الخطة الأسبوعية، ملاحظات الأسرة المؤرخة، وآخر 50 سؤالًا من الشات محليًا على الجهاز. يظهر تنبيه مع زر إعادة المحاولة عند تعذّر القراءة أو الحفظ. التغييرات تُكتب بالترتيب حتى لا يطغى حفظ قديم بطيء على حفظ أحدث.

## خطة الأسبوع وتقرير الطبيب

خطة الأسبوع تختار ثلاث لحظات لعب من المرحلة الحالية، وتعطي الأولوية للمهارات المسجلة «بيحاول» ثم «لسه ملاحظتهاش». كل نشاط قصير، له هدف واضح، ويُعلّم عليه للأسبوع الحالي من غير تحويل المتابعة لاختبار للطفل.

تقرير الطبيب يعرض المرحلة الحالية، الحالات المسجلة في المراحل السابقة، ملاحظات الأسرة بتواريخها، والأسئلة المحفوظة من الشات. على الويب يفتح نافذة الطباعة للحفظ PDF، وعلى iOS وAndroid ينشئ PDF ويفتح قائمة المشاركة. التقرير ملخص لملاحظات الأسرة، وليس تشخيصًا أو اختبار فحص معتمدًا.

## الاعتماديات

الإصدارات متوافقة مع SDK 57. يوجد override لـUUID المستخدم داخل `xcode`، ونسخة مصححة من `query-string` داخل React Navigation. تصحيح صغير محفوظ في `patches/` يكيّف استيراد `query-string` مع واجهتها الحديثة؛ يطبقه `patch-package` أثناء `npm ci`/`npm install`. اختبارات التنقل تتحقق من قراءة وكتابة معاملات URL العربية. عند تحديث React Navigation، راجعي التصحيح وأزيليه إن أصبح غير مطلوب.

## نشر الويب

النسخة المنشورة سابقًا: [MUMAI على GitHub Pages](https://mohamed-elrady.github.io/MUMAI/).

```bash
npm run deploy
```

ده يبني الويب وينشره على فرع `gh-pages`. المسار `experiments.baseUrl` مضبوط على `/MUMAI`. التعديلات المحلية لا تظهر في النسخة المنشورة إلا بعد النشر.
